# TEAO Website Project Rules

## Public Content Language

TEAO is an English international independent website. All content deployed or written into public-facing webpages must be in English by default.

This includes public page copy, news/blog articles, product and category content, SEO titles, meta descriptions, keywords, structured data, image alt text, button labels, CTAs, downloadable-resource prompts, database-backed public content, and any other text visible on the public website.

Chinese user input can be used as source material, but it must be translated, localized, and polished into natural English before being inserted into the website, database, or deployment-ready content artifacts. Do not publish Chinese public-facing content unless the user explicitly asks for a bilingual or Chinese-specific page.
